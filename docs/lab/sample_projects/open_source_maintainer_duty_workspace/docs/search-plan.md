# 检索计划

## 要回答的问题

1. issue 分级时哪些状态需要立即处理。
2. release blocker 解除需要哪些证据。
3. 回归测试证据应记录命令、环境和结果到什么粒度。
4. 交接记录如何让下一位维护者不用重读所有 issue。
5. public README/changelog 发布前要扫描哪些私有信息。
6. 恢复记录如何被下一次相似失败复用。

## 本地优先材料

- issue 或 PR 导出。
- release checklist。
- CI 或测试命令说明。
- README/changelog 草稿。
- 历史事故或恢复记录。
- 安全披露政策。

## 停止条件

当 duty board 中每个 blocker 都有解除条件，每条回归证据都可复查，每份 public material 都经过边界检查，且未读取材料有明确原因时，可以进入发布或交接。
