# 原始需求记录

## 用户原话

我需要一个面向非营利组织项目申请的工作区。它要帮助我把不同资助方的申请要求、项目预算、受益人证据、申请材料草稿、提交截止日期和后续复盘联系起来。

这个工作区不是只保存一段申请说明，而是要让我能比较不同资助方的要求，知道每份材料还缺什么证据，知道预算数字来自哪里，知道每个截止日期前谁要做什么。提交后还要能记录资助方反馈、拒绝理由、需要补充的证据、下次申请窗口和下一步动作。

请保留原始申请意图，把需求整理成可执行的项目结构，生成材料准备 workflow，保留证据来源，最后提供一个本地验证脚本检查关键文件、索引和数据结构是否齐全。不要把样例名写成 Nexus 的特殊逻辑。

## 用户边界

- 不要求连接真实资助方网站，不做自动投递。
- 不要求生成正式财务报表，只维护申请工作区所需的预算追踪字段。
- 不允许把未确认的资助方规则写成已确认事实。
- 公开材料和内部预算/联系人记录必须分开说明。

## 手工样例说明

本文件是人工构造的高质量样例，用于说明 Codex 在充分理解用户意图后应交付的项目工作区形态。它不是 Nexus 自动生成结果。
