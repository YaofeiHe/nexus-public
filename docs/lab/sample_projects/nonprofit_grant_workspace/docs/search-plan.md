# 检索计划

本样例不执行联网检索，但保留检索计划，说明真实项目初始化时应该先问清或读取哪些材料。

## 要回答的问题

1. 资助方要求字段：不同资助方至少要比较哪些字段。
2. 证据材料来源：受益人数据、访谈、服务记录如何证明项目影响。
3. 预算字段：哪些金额能公开，哪些只应保留内部追踪。
4. 截止日期和责任人：如何在提交前发现阻断项。
5. 反馈复盘：被拒或待补材料如何回到下一轮申请准备。

## 本地优先材料

- 历史申请草稿。
- 预算表或费用明细。
- 受益人统计和授权说明。
- 资助方邮件或申请指南。
- 过往被拒反馈或复盘会议纪要。

## 停止条件

当每个资助方记录都能填充资格、材料、预算、证据、截止日期和复盘字段，且未读取材料都有明确原因时，可以进入申请包构建。
