## 读取结论

三个 reference pack 的作用不同：`strategy_notes.md` 决定领域结构，`prior_chat_excerpt.md` 决定协作规则和验收口径，`existing_files_index.md` 决定初始化前的材料盘点。后续 Nexus 不能只保存文件路径，必须把提取出的要求写回 workflow、schema 和 validator。
