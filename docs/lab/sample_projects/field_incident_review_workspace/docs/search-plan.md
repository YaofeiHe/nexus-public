# 检索计划

## 目标

在生成项目结构前，先回答以下问题：

1. 事故复盘需要记录哪些事实字段。
2. 根因分析如何区分假设、证据、反证和未确认事项。
3. 整改行动如何定义关闭标准。
4. 每周领导摘要应该公开哪些内容、隐藏哪些内部细节。
5. 用户纠正如何转成项目规则，而不是只作为聊天背景。

## 必读来源

- `reference_pack/strategy_notes.md`：抽取业务对象和 workflow。
- `reference_pack/prior_chat_excerpt.md`：抽取用户协作规则。
- `reference_pack/existing_files_index.md`：抽取既有文件盘点方式。

## 停止条件

只有当每份来源材料都记录读取状态、提取结果和未覆盖事项后，才能生成或更新项目文件。
