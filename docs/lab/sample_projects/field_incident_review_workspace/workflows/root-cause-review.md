# Workflow: 根因复盘

## 触发条件

事故已有足够事实材料，需要从“发生了什么”进入“为什么发生”和“如何避免复发”。

## 步骤

1. 读取目标事故的 intake 记录和来源材料。
2. 为每个 root-cause hypothesis 填写支持证据、反证和可信度。
3. 把仍不确定的问题写入 `open_questions`，不要写成结论。
4. 将根因假设连接到整改行动。
5. 更新 `docs/search-log.md`，说明本轮新增证据或跳过材料。
6. 运行 `python3 scripts/validate_project.py`。

## 验收

- 每个根因假设都有证据或明确说明为什么待确认。
- 反证被保留，不因结论倾向而删除。
- 根因和整改行动之间有可追踪关系。
